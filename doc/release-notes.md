# TabForge 0.5.0

新增目录自动发现：程序预先配置类型与匹配规则，策划新增、删除同类型文件后直接导出，不再维护 Index.csv。旧索引模式继续可用；未知表、规则冲突、重复索引值和非法数据会阻止发布，保留上一版产物。

新增 Unreal 编辑器与数据源码插件，提供创建示例、校验、导出并导入、独立导入、取消和错误报告。运行时加载经过结构校验的 ProtoJSON 快照，64 位整数保留为字符串。完整交付集新增四个平台的 Unreal 插件 ZIP，共 29 个安装包。

GitHub 标签发布工作流从干净提交构建，执行自动化回归与独立消费验收，生成带版本、提交、SHA-256 和验收报告的交付目录。公共包仓库和插件市场发布流程已准备，但本次不上传 npm、PyPI、Maven Central 或市场。

修复 Windows 自动化验收中的文件 URL 转路径问题，并统一 Python 验收文件使用 UTF-8，避免系统默认编码影响中文数据。生成示例通过 Git attributes 保持原始字节，避免自动 CRLF 转换破坏文件校验和。

本版本以 GitHub prerelease 交付。Unreal 引擎编译、所有编辑器 UI 安装交互、Windows/Intel 原生执行、下载隔离与签名公证不在本次验收范围；不能把工具层自动化检查理解为引擎实测通过。
